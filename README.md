# My Budget Tracker

## About the Project

My Budget Tracker is a simple HTML and CSS project that helps users view and organize their expenses. This project was built by upgrading the Budget Tracker from Week 1.

## Features

* Add Expense form
* Expense category dropdown
* Expense table with sample data
* Budgeting tips video
* Budget tracker image
* Collapsible instructions section
* Table hover effects
* Input focus effects
* Responsive table and video styling

## Files

### index.html

The `index.html` file contains the structure of the Budget Tracker.

It includes:

* Main heading and introduction
* Add Expense form
* Expense name and amount inputs
* Category dropdown
* Add Expense button
* Expense table
* Sample expense data
* Budgeting tips video
* How to use the tracker section

### style.css

The `style.css` file controls the appearance of the Budget Tracker.

It includes:

* Page and section styling
* Form styling
* Table borders and spacing
* Colored table header
* Alternating table rows
* Table hover effect
* Button styling
* Input focus effects
* Video styling
* Collapsible section styling
* Advanced CSS selectors

## Technologies Used

* HTML5
* CSS3
